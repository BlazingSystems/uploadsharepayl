# Upstream & Attribution

This project is an independently maintained ESP8266/dual-control adaptation informed by the following MIT-licensed NRSuite repositories:

- NRSuite Android: https://github.com/7wp81x/NRSuite-Android
- NRSuite firmware: https://github.com/7wp81x/NRSuite-firmware
- NRSuite protocol: https://github.com/7wp81x/NRSuite-Protocol

The NRSuite names and upstream copyright remain with their respective authors.

The ESP8266 port preserves protocol compatibility for a defensive subset but is not an official upstream build. Unsupported capabilities are intentionally omitted rather than emulated inaccurately.
